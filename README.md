# BASE: REBUILD — PWA для GitHub Pages, v0.8

**Дата:** 28 октября 2026  
**Этап:** v0.8 — ежедневные RPG-квесты, реальные XP, уровни и шесть характеристик. Полный MVP ещё не завершён.

## Публикация через GitHub Pages

Рекомендуемое название публичного репозитория: `base-rebuild`. Адрес будет `https://dmitriyribka27.github.io/base-rebuild/`.

Сайт уже опубликован: **https://dmitriyribka27.github.io/base-rebuild/**. Исходники и собранная папка `docs` находятся в `main`. GitHub Pages настроен на публикацию из `main /docs`.

На iPhone открой ссылку в Safari, нажми `Поделиться → На экран «Домой»` и включи запуск как веб-приложения.

**При обновлениях:** меняем исходный код, выполняем `npm run build` и отправляем изменённые файлы вместе с `docs` в GitHub. GitHub Pages обновляется из папки `docs`.

**ВАЖНО:** URL нового сайта имеет другой адрес хранения IndexedDB. Старые задачи из приватной версии ChatGPT *не появятся автоматически*. В старой версии открой настройки, экспортируй JSON, затем восстанови этот файл на новом сайте. Не удаляй старое приложение до проверки восстановления.

## PWA и приватность

- `public/manifest.webmanifest` — имя, стартовый экран, значки и полноэкранный режим.
- `public/icons/` — неоновая иконка BASE и PNG для iPhone.
- `scripts/build-sw.mjs` — формирует `docs/sw.js` с офлайн-кэшем при каждой сборке.
- После **первой успешной онлайн-загрузки** приложение может открываться без интернета, но iOS вправе очищать кэш и локальное хранилище при нехватке места. Данные IndexedDB и офлайн-кэш — **разные** механизмы.
- Нет серверной базы, авторизации, аналитики, синхронизации или автоматической выгрузки записей. JSON-экспорт выполняется только вручную.
- Публичный GitHub Pages-сайт доступен любому по ссылке. Другие посетители увидят пустое приложение, не твои локальные задачи.

## Что работает

- **Дом**: утверждённая комната и персонаж из пользовательского изображения (без изменений).
- **Ежедневные квесты**: семь ручных отметок внизу режима «День» планера: «Слово = действие» (25 XP), «Инициатива дома» (20), «Бережный контакт» (15), «Восстановление» (15), «Честный вечерний отчёт» (15), «Никотиновый журнал» (5), «Маленькая радость» (5). Итого не более 100 XP в день. Обычные задачи и коллекции XP не дают.
- **Уровни и характеристики**: по 700 XP на уровень, названия первых десяти уровней и независимый XP шести характеристик. XP производный от реальных отметок, не хранится второй противоречащей суммой. Вкладка «Прогресс» показывает XP по характеристикам, историю дней, оставшийся XP до уровня и 90-дневную программу.
- **Защита отметок**: одна запись в IndexedDB на сочетание даты и квеста, повторное нажатие не дублирует награду. Ошибочную отметку можно отменить, и XP пересчитается. Квесты будущих дат нельзя отметить заранее, а прошлые даты доступны для честного исправления.
- **Дневник**: записи на любую выбранную дату, время сна и пробуждения, энергия и настроение (1–10), число сигарет (ноль отличается от незаполненного поля), активность, события, сложности, выводы, работа, дом, финансы и планы на завтра. Все поля необязательны, изменения сохраняются локально.
- На iPhone выбор времени сна и пробуждения отображается двумя компактными строками с собственным точно центрированным отображением значений. Невидимый нативный элемент `type=time` остаётся активным поверх плашки для открытия системного выбора времени. Шапка PWA учитывает верхнюю безопасную область устройства.
- **Завершить день**: предварительный просмотр текстового отчёта из фактических записей дневника, квестов и задач планера с реальными XP и уровнем на выбранную дату; дополнение личным комментарием, копирование в буфер обмена для ручной отправки в ChatGPT, история отчётов за предыдущие даты. Доступен системный диалог «Поделиться» при поддержке браузером.
- **Переносы задач**: при изменении даты обычной задачи фиксируется событие переноса, которое попадает в соответствующий дневной отчёт.
- **Сегодня**: лента дат, выбор дня, раскрывающиеся группы задач.
- **Списки**: семь пустых тематических коллекций (без вымышленных пользовательских пунктов), а также создание и изменение своих коллекций.
- Добавление, редактирование, отметка выполнения и мягкое удаление с восстановлением пунктов. Прогресс коллекции, теги и фильтры, сортировка пунктов стрелками вверх/вниз.
- Перенос пункта в планер на выбранную дату и в нужную группу. У одного пункта не бывает двух активных связанных задач: повторное планирование переносит существующую. Выполнение и отмена выполнения синхронизируются в обоих направлениях.
- Добавление задачи: название, группа, дата, необязательное время, приоритет и заметка.
- Редактирование, перенос на другой день, выполнение и отмена выполнения.
- Повторы: ежедневно, по будням, еженедельно по дню старта, ежемесячно по числу старта; необязательная дата окончания. У каждого дня повтора своя независимая отметка выполнения.
- Управление группами: создание, переименование, значок, подпись, скрытие пустых групп и их восстановление. Переименование не разрывает связи с задачами.
- Реальные обзоры недели и месяца: список дел по дням и суммарный прогресс; месячная сетка показывает количество задач на каждую дату.
- Фильтры: все/открытые/готово, по группе; сортировка по времени, важности и новизне.
- Мягкое удаление в корзину с возможностью восстановления из настроек.
- Редактирование и удаление повторяющейся задачи относится ко **всей серии**, не к отдельному дню.
- Отдельный прогресс выполнения для выбранной даты.
- Сохранение задач в IndexedDB после каждого изменения.
- Версионированная резервная копия JSON и восстановление с проверкой формата и явным подтверждением замены данных. Файлы v0.3–0.7 принимаются.
- Используется часовой пояс Asia/Tbilisi для календарных дат.

## Сохранность данных и совместимость

Схема IndexedDB увеличена до версии **5**. При обновлении прежние таблицы `tasks`, `groups`, `occurrences`, `collections`, `collectionEntries`, `journals`, `dailyReports`, `taskMoves` **не очищаются**. Добавляется только `questCompletions`.

JSON-копии v0.3 (`schemaVersion: 1`) импортируются со стандартными группами. Копии v0.4–0.5 (`schemaVersion: 2`) содержат задачи, группы и отметки повторов. В обоих случаях добавляются пустые коллекции без пользовательских данных. Копии v0.6 (`schemaVersion: 3`) включают пять типов записей и стабильные ссылки пунктов на задачи. Копии v0.7 (`schemaVersion: 4`) также содержат дневники, сохранённые отчёты и историю переносов. Новые копии v0.8 (`schemaVersion: 5`) включают отметки RPG-квестов. Старые копии не получают выдуманных XP или записей дневника. Восстановление заменяет данные только после явного подтверждения и выполняется одной транзакцией.

## Ограничения

При первом запуске список задач пуст. Старые демонстрационные задания не импортируются и не выдаются за пользовательские записи. Хранилище браузера не синхронизируется с другими устройствами.

Пока не готовы произвольные трекеры, достижения и крупные миссии с отдельной системой наград; облачная синхронизация сознательно исключена из этого локального продукта. Характеристика «Финансы» остаётся с нулевым XP до появления соответствующих миссий: финансовых квестов в стартовой семёрке нет. Для повторяющихся задач пока нельзя отдельно перенести или исключить только один день. Удалённые пункты коллекции можно восстановить, а архивные коллекции вернуть; физическое стирание отдельных записей в интерфейсе не используется. Системное копирование и «Поделиться» требуют отдельной проверки в Safari на iPhone.

## Разработка

Требуется современный Node.js.

```bash
npm install
npm run dev
npm run test:logic
npm run build
npm run test:pwa
```

Сборка Vite создаёт `docs/`, после чего генератор формирует офлайн-кэш. Веб-ассеты используют относительные адреса, поэтому работают в подпапке GitHub Pages. Проверка `test:pwa` убеждается, что стартовые файлы, иконки и ссылки кэша действительно присутствуют.
