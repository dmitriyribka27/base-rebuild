# BASE: REBUILD — PWA для GitHub Pages, v0.5

**Дата:** 28 октября 2026  
**Этап:** v0.4 планер без изменений + самостоятельная устанавливаемая PWA-сборка v0.5. Полный MVP ещё не завершён.

## Публикация через GitHub Pages

Рекомендуемое название публичного репозитория: `base-rebuild`. Адрес будет `https://dmitriyribka27.github.io/base-rebuild/`.

1. Создай **публичный** репозиторий `base-rebuild` в GitHub, без добавления шаблонных файлов. GitHub Pages на бесплатном плане работает с публичным репозиторием.
2. Загрузите содержимое папки проекта в ветку `main` (не ZIP как единственный файл). **Папка `docs` уже содержит готовый сайт**, а остальной код оставлен для будущих обновлений.
3. В репозитории открой `Settings → Pages`.
4. В разделе `Build and deployment` выбери `Source: Deploy from a branch`, затем `Branch: main`, `Folder: /docs`, `Save`.
5. После публикации открой ссылку на iPhone в Safari. Нажми `Поделиться → На экран «Домой»` и выбери запуск как веб-приложения.

**При обновлениях:** меняем исходный код, выполняем `npm run build` и отправляем изменённые файлы вместе с `docs` в GitHub. GitHub Pages обновляется из папки `docs`.

**ВАЖНО:** URL нового сайта имеет другой адрес хранения IndexedDB. Старые задачи из приватной версии ChatGPT *не появятся автоматически*. В старой версии открой настройки, экспортируй JSON, затем восстанови этот файл на новом сайте. Не удаляй старое приложение до проверки восстановления.

## PWA и приватность

- `public/manifest.webmanifest` — имя, стартовый экран, значки и полноэкранный режим.
- `public/icons/` — неоновая иконка BASE и PNG для iPhone.
- `scripts/build-sw.mjs` — формирует `docs/sw.js` с офлайн-кэшем при каждой сборке.
- После **первой успешной онлайн-загрузки** приложение может открываться без интернета, но iOS вправе очищать кэш и локальное хранилище при нехватке места. Данные IndexedDB и офлайн-кэш — **разные** механизмы.
- Нет серверной базы, авторизации, аналитики, синхронизации или автоматической выгрузки записей. JSON-экспорт выполняется только вручную.
- Публичный GitHub Pages-сайт доступен любому по ссылке. Другие посетители увидят пустое приложение, не твои локальные задачи.

## Что работает

- **Дом**: утверждённая комната и персонаж из пользовательского изображения (без изменений).
- **Сегодня**: лента дат, выбор дня, раскрывающиеся группы задач.
- Добавление задачи: название, группа, дата, необязательное время, приоритет и заметка.
- Редактирование, перенос на другой день, выполнение и отмена выполнения.
- Повторы: ежедневно, по будням, еженедельно по дню старта, ежемесячно по числу старта; необязательная дата окончания. У каждого дня повтора своя независимая отметка выполнения.
- Управление группами: создание, переименование, значок, подпись, скрытие пустых групп и их восстановление. Переименование не разрывает связи с задачами.
- Реальные обзоры недели и месяца: список дел по дням и суммарный прогресс; месячная сетка показывает количество задач на каждую дату.
- Фильтры: все/открытые/готово, по группе; сортировка по времени, важности и новизне.
- Мягкое удаление в корзину с возможностью восстановления из настроек.
- Редактирование и удаление повторяющейся задачи относится ко **всей серии**, не к отдельному дню.
- Отдельный прогресс выполнения для выбранной даты.
- Сохранение задач в IndexedDB после каждого изменения.
- Версионированная резервная копия JSON и восстановление с проверкой формата и явным подтверждением замены данных. Файлы v0.3 тоже принимаются.
- Используется часовой пояс Asia/Tbilisi для календарных дат.

## Сохранность данных и совместимость

Схема IndexedDB увеличена с версии 1 до 2. При обновлении прежняя таблица `tasks` **не очищается**: добавляются отдельные таблицы `groups` и `occurrences`. Задачи v0.3 остаются на месте.

JSON-копии v0.3 (`schemaVersion: 1`) импортируются с прежними задачами и стандартными группами. Новые копии v0.4 (`schemaVersion: 2`) содержат задачи, группы и отметки повторов. Восстановление заменяет все данные только после явного подтверждения и выполняется одной транзакцией.

## Ограничения

При первом запуске список задач пуст. Старые демонстрационные задания не импортируются и не выдаются за пользовательские записи. Хранилище браузера не синхронизируется с другими устройствами.

Пока не готовы коллекции, трекеры, дневник, XP-квесты, экспорт дневного отчёта и облачная синхронизация. Для повторяющихся задач пока нельзя отдельно перенести или исключить только один день. Уровень и XP на главной остаются стартовыми.

- `src/techno.css` — неоновая сине-чёрная тема интерфейса;
- `src/planner.css` — элементы рабочей формы и управления данными;

- `docs/` — готовые для GitHub Pages статические файлы (создаются сборкой, включены в архив).

## Разработка

Требуется современный Node.js.

```bash
npm install
npm run dev
npm run test:logic
npm run build
npm run test:pwa
```

Сборка Vite создаёт `docs/`, после чего генератор формирует офлайн-кэш. Веб-ассеты используют относительные адреса, поэтому работают в подпапке GitHub Pages. Проверка `test:pwa` убеждается, что стартовые файлы, иконки и ссылки кэша действительно присутствуют.
